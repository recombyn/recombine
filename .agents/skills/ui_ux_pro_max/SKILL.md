# UI/UX Pro Max — Design Intelligence

开源改编自 [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)（MIT）。给 Design Agent 用的画布决策百科，不是 IDE 脚本。

## 何时加载

- 新建落地页 / Dashboard / SaaS / 移动物料
- 选风格、配色、字体、间距与信息层级
- 审查可读性、无障碍、触控与反馈

## 优先级检查（高 → 低）

1. **无障碍**：正文对比度 ≥ 4.5:1；可见焦点环；图标按钮有可读名称；勿仅靠颜色传达状态
2. **触控与反馈**：可点区域够大；加载/禁用有反馈；勿只靠 hover
3. **风格一致**：选定一种风格语言后贯彻到底（玻璃 / 极简 / 粗野 / 扁平…），勿混用互斥语言
4. **布局**：移动优先；避免横向溢出；层级清晰（主视觉 → 支撑 → 次要）
5. **字体与颜色**：正文字号可读；语义色（主色 / 危险 / 静音）统一；组件内勿散落随意 hex
6. **动效**：150–300ms；有意义；尊重减少动态偏好
7. **表单**：可见标签；错误就近；勿只用 placeholder 当标签

## 风格选型提示

| 物料 | 倾向 |
|------|------|
| SaaS / 后台 | 清晰层级、克制色、可扫描表格与表单 |
| 落地页 / 品牌 | 明确主视觉 + CTA；留白或受控密度二选一 |
| 电商主图 | 主体最大；角标克制；少干扰 |
| Banner | 文案在中部安全带；对比够 |

## 画布落地

- 先定物料与尺寸，再落层；节点 id 只用 SCENE 已有
- 配色 / Banner 像素等数字细则可再 `need_knowledge`
- 落层坐标与 op 对照交给 layout / canvas 类 skill，本 skill 负责质量门槛与选型
