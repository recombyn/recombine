# 自訂與第三方模型

你可以在 recombyn 裡接入**自己的 API Key**（BYOK），用相容 OpenAI / Claude 風格的第三方服務，而不只走平台內建模型。

入口：**帳戶設定 → Agent → 第三方模型**。儲存後，模型會出現在對話區底部的**模型列表**裡，可直接選用。

## 誰可以新增？

| 環境 | 條件 |
|------|------|
| **網頁 / 雲端桌面** | 一般需 **標準檔（Plus）及以上**會員；未開通時介面會提示升級 |
| **桌面端本地版** | 不依賴平台會員；本地版本身沒有平台模型目錄，**需要自己配第三方 Key** 才能對話 / 出圖 |

Key 與端點保存在本機；呼叫走你自己在供應商側的額度，**不扣平台積分**。同一會話裡若仍用了平台生圖、去背景等能力，那些步驟仍按平台規則計費。

## 兩種新增方式

### 1. 平台目錄（建議）

列表裡會有內建平台（如 **OpenRouter**、**火山方舟 / 豆包** 等，以產品內實際為準）。

1. 選中某個平台。
2. 一般**只需貼上 API Key**（請求位址、常用模型會自動填好）。
3. 點儲存。該平台目錄裡已接入的對話 / 圖片 / 影片模型會出現在模型選擇列表中。

部分平台還支援 **「新增模型」**：在已儲存 Key 的前提下，把目錄裡沒有的模型 ID 補進列表。

### 2. 手動填寫

選 **「手動填寫」**，自己配任意相容端點：

| 欄位 | 說明 |
|------|------|
| **模型類型** | **對話** / **多模態** / **圖片** / **影片** |
| **供應商名稱** | 顯示用 |
| **官網連結** | 可選 |
| **模型 ID** | 上游 `model` 欄位，不是顯示名 |
| **API Key** | 供應商金鑰 |
| **請求位址** | `http(s)://` 開頭，**不要**以 `/` 結尾 |

## 計費與積分

| 呼叫 | 是否扣平台積分 |
|------|----------------|
| 第三方 / 平台目錄 BYOK | **不扣** |
| 平台自帶模型、平台生圖、圖片工具 | **仍扣** |
