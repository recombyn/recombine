# 帳戶與積分

## 開啟帳戶

登入後，從頭像 / 帳戶入口開啟設定。常見分區：

| 分區 | 內容 |
|------|------|
| **個人資料** | 顯示名、簡介、頭像 |
| **方案** | 會員檔位、權益、升級 |
| **積分 / 錢包** | 餘額、預估消耗 |
| **用量與帳單** | 儲值與模型消耗流水 |
| **卡密兌換** | 會員套餐或積分儲值 |
| **Agent** | Auto 路由偏好、第三方模型 |

## 統一積分

錢包只有一種貨幣：**積分**。

- **對話 / Agent**：依模型用量折算積分後扣除。
- **文生圖 / 部分圖片工具**：按張或按次扣積分。
- 會員每月贈送統一額度；對話、Agent、出圖**共用同一餘額**。
- **第三方自有 Key** 的聊天呼叫**不扣**平台積分（平台生圖等仍可能扣費）。見 [自訂與第三方模型](/guide/custom-models)。

餘額不足時會無法傳送或出圖，需升級、兌換卡密或等待免費檔每日試用重置。

## 會員方案

| 檔位 | 大致定位（以產品內方案頁為準） |
|------|--------------------------------|
| **免費** | 不贈月度積分；每天有限次設計執行（通常僅 Auto） |
| **標準（Plus）** | 每月贈送積分；可自選平台模型；可新增第三方模型 |
| **專業（Pro）** | 更高月度積分；第三方模型與更深能力 |
| **旗艦（Ultra，若上架）** | 最高額度與優先體驗 |

卡片上的「約合 N 次對話 / N 張圖」為**估算**，實際因模型與提示長度而異。

### 方案切換注意

- 付費方案在有效期內通常**不可切換**；到期後可再換。
- 同檔續期或**積分卡密**仍可兌換（以兌換提示為準）。

## 用量與帳單

在 **用量與帳單** 可查看儲值 / 贈送到帳，以及對話、Agent、出圖消耗。若生成失敗且未退回，請保留時間點並在產品內回饋。

## 卡密兌換

1. 開啟兌換入口，輸入卡密（格式多為 `XXXXX-XXXXX-XXXXX-XXXXX`）。
2. 常見類型：
   - **會員套餐**：開通方案並到帳月度積分
   - **積分儲值**：直接增加積分餘額
3. 成功後立即生效；除法規或產品明確承諾外，通常不支援無理由退款。

## Agent 偏好（帳戶 → Agent）

與編輯器內 Auto 彈層共用本機設定。

### Auto 路由

| 偏好 | 作用 |
|------|------|
| 標準版 | 跟隨平台預設車道表 |
| Pro / Max | 使用更強的預設車道→模型對應 |
| 自訂車道 | 分別為輕量 / 標準 / 推理 / 多模態 / 生圖指定模型 |

**僅聊天模型為 Auto 時生效。** 詳見 [Agent 用法 · Auto 路由偏好](/guide/agent#auto-路由偏好)。

### 第三方模型

支援**平台目錄**（多半只需 API Key）與**手動填寫**（模型 ID、請求位址；含對話 / 多模態 / 圖片 / 影片）。詳見 [自訂與第三方模型](/guide/custom-models)；桌面見 [桌面端](/guide/desktop)。

## 個人資料

- 可修改顯示名、簡介與頭像（上傳至物件儲存）。
- 登入方式：信箱或 Google（依註冊時為準）。
- 信箱帳號可在設定中**修改密碼**；純 Google 登入通常沒有信箱密碼可改。

## 通知公告

帳戶設定中的 **通知公告** 可查看公告與系統通知，可標記全部已讀。
