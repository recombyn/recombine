# 匯出與分享

## 匯出

編輯器頂部 **Export**：

- **目前畫板**、**選取內容**或**匯出全部頁面**（多畫板時）
- 格式：PNG / JPG / SVG（以產品選項為準）
- 倍率約 0.5x–4x
- 單節點也可從工具列匯出或全螢幕預覽

多畫板請確認匯出範圍。

## 分享連結

**Share** 可產生連結：

| 類型 | 說明 |
|------|------|
| **僅預覽** | 持連結即可查看，**無需登入** |
| **可編輯** | 需登入；僅**擁有者與受邀協作者**可改稿並儲存 |

未開啟公開連結時，通常僅協作者可存取。請勿在公開預覽連結放置敏感資訊。

## 邀請協作者

在分享面板可依**使用者名稱 / 信箱 / 使用者 ID** 邀請：

1. 開啟 **Share** → 邀請協作。
2. 搜尋並新增對方。
3. 對方登入後即可在授權範圍內編輯。

可在協作者列表管理成員。
