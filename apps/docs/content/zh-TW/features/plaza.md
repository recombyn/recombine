# 廣場與靈感

瀏覽**官方案例**與社群作品，並一鍵開啟到自己的編輯器。

## 瀏覽

- 首頁與廣場：**推薦 / 最新 / 我的關注** 等。
- 品類：網站、行動應用、圖片、海報、繪畫等。
- **官方案例**：平台提供的高品質範本 / 範例。
- 開啟後會複製到你的專案，可手改或交給 Agent。

## 發佈到廣場

1. 準備封面畫板（多畫板時選代表性頁面）。
2. 填寫標題等並提交。
3. 需**管理員審核**通過後才公開。

請勿發佈侵權或違規內容（見 [服務條款](/legal/terms)）。

## 個人主頁

| 分區 | 說明 |
|------|------|
| **已發佈** | 審核通過的廣場作品 |
| **我的喜歡** | 你按讚過的內容 |
| **資產** | 相關素材入口（以產品為準） |

與編輯器內專案庫相互獨立。
