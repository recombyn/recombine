# 常見問題

## 登入與賬戶

**收不到驗證碼？**  
檢查垃圾郵件；確認郵箱拼寫；等待冷卻時間後再試。

**Google 登入失敗？**  
確認瀏覽器允許彈窗 / 第三方 Cookie；或改用郵箱登入。

## 積分與計費

**為什麼扣了積分但沒結果？**  
生成失敗時多數情況下會退回；若未退回請保留時間點並在產品內反饋。可在帳戶「用量與帳單」核對流水。

**免費額度用完了？**  
可等待次日試用重置，或升級方案 / 兌換卡密。

**圖片工具扣多少分？**  
去背景、放大、調整、擴充套件、多角度等有固定參考消耗；文生圖按模型與張數計費。詳見 [圖片編輯工具](/guide/image-tools) 與按鈕旁數字。

**第三方模型扣平台積分嗎？**  
自有 Key 的聊天 / 多模態呼叫不扣平台積分；同一工作階段的平台生圖與圖片工具仍扣費。見 [Agent 用法](/guide/agent#第三方大模型自有-key) 與 [帳戶與積分](/guide/account)。

**帳單在哪裡看？**  
帳戶 → 用量與帳單。詳見 [帳戶與積分](/guide/account)。

## 畫布與同步

**首頁封面不是最新稿？**  
離開編輯器時會強制同步文件與封面；硬重新整理首頁。若仍舊，在畫布再改一筆儲存後返回。

**重新整理後畫布內容丟了？**  
登入態下以雲端為準；確認已登入且網路正常。本地草稿會盡量保留未同步編輯。

**圖層面板看不到畫板？**  
畫板與形狀 / 圖片等會一起出現；可顯隱、鎖定並調整疊放。見 [畫布與工具](/guide/canvas)。

## Agent 與出圖

**Agent / 詢問 / 圖片有什麼區別？**  
Agent 直接改畫布；詢問只答方案（可再確認執行）；圖片專注生圖。見 [Agent 用法](/guide/agent)。

**檢查點撤銷後重新整理又回來了 / 提示快照失效？**  
部分檢查點僅當前工作階段有效。重要結果請及時保留或匯出。見 [Agent 用法 · 檢查點](/guide/agent#檢查點與還原)。

**Auto 選的模型不對？**  
在帳戶 → Agent（或模型彈層裡的 Auto 路由）調整標準版 / Pro / Max，或改用**自訂車道**；也可手動鎖定模型。見 [Agent 用法 · Auto 路由](/guide/agent#auto-路由偏好)。

**自訂車道會一次呼叫五個模型嗎？**  
不會。每輪只走一條聊天車道（需要時另加生圖）。

**怎麼新增第三方大模型？**  
開通對應方案後，在帳戶 → Agent 填寫供應商、API Key、相容端點與模型類型並儲存。見 [Agent 用法 · 第三方大模型](/guide/agent#第三方大模型自有-key)。

**生圖很慢或失敗？**  
檢查積分、網路與所選模型狀態；換模型或降低解析度 / 張數重試。

**多張圖生成後怎麼切換？**  
選中圖片節點展開「N 張圖」，可設為主圖或單獨成節點。見 [圖片編輯工具](/guide/image-tools)。

## 廣場、匯入與分享

**發佈到廣場一直未展示？**  
需管理員審核；未通過時按反饋修改後重提。見 [廣場與靈感](/features/plaza)。

**匯入後排版亂？**  
建議再調畫板尺寸與圖層，或讓 Agent 統一整理。見 [匯入檔案](/features/import)。

**分享連結別人改不了？**  
「僅預覽」本來就不能改。「可編輯」需要對方登入，且已被邀請為協作者。見 [匯出與分享](/features/export-share)。
