# ファイルのインポート

ホームからローカルファイルを編集可能なキャンバスへ。

| 種類 | 説明 |
|------|------|
| **画像** | 画像ノード。[画像ツール](/guide/image-tools) / Agent |
| **PDF** | 可能な範囲で構造化 |
| **Word** | 編集可能な内容へ |

1. インポート → 解析 → エディタ。  
2. アートボードサイズを確認。  
3. [レイヤー](/guide/canvas) で整理。  
4. Agent でスタイル統一、必要なら手修正。

複雑な PDF / Word は完全再現ではありません。スキャン PDF は全ページ画像になりがちです。
