# 書き出しと共有

## 書き出し

**Export**：現在のアートボード / 選択 / 全ページ。PNG / JPG / SVG。倍率約 0.5x–4x。ノードツールバーからも可。

## 共有リンク

| 種類 | 説明 |
|------|------|
| **閲覧のみ** | リンクで閲覧。**ログイン不要** |
| **編集可** | ログイン必須。**所有者と招待コラボのみ**保存可 |

公開リンクオフ時は通常コラボのみアクセス可。

## コラボ招待

Share でユーザー名 / メール / ID から招待。相手がログインし、コラボ一覧に入っている必要があります。
