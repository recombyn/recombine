# アカウントとクレジット

## アカウントを開く

ログイン後、アバター／アカウントから設定を開きます。

| 区分 | 内容 |
|------|------|
| **プロフィール** | 表示名、自己紹介、アバター |
| **プラン** | 会員ランク、特典、アップグレード |
| **クレジット／ウォレット** | 残高、見込み消費 |
| **利用と請求** | チャージとモデル消費の明細 |
| **カードキー交換** | 会員またはクレジット追加 |
| **Agent** | Auto ルーティング、サードパーティモデル |

## 統一クレジット

通貨は **クレジット** のみです。

- **チャット / Agent**：用量をクレジット換算して減算。
- **画像生成／一部画像ツール**：枚数または回数で減算。
- 会員の月次付与はチャット・Agent・画像で**共有**。
- **自前 Key** のチャットはプラットフォームクレジットを**消費しません**（プラットフォーム画像機能は対象外）。[Agent · サードパーティ](/guide/agent#サードパーティモデル自前-key) 参照。

残高不足時は送信／生成がブロックされます。プラン変更・キー交換・無料日次リセットを利用してください。

## プラン

| ランク | 目安（製品内プランページ準拠） |
|--------|--------------------------------|
| **無料** | 月次付与なし。1 日あたり限られた実行（多くは Auto のみ） |
| **Standard (Plus)** | 月次クレジット。プラットフォームモデル選択とサードパーティ追加可 |
| **Pro** | より多い月次クレジット。カスタムモデル等 |
| **Ultra**（提供時） | 最高枠と優先体験 |

カード上の「約 N 回チャット / N 枚」は**目安**です。

### プラン変更

- 有料期間中は通常**他プランへ変更不可**。期限後に変更可。
- 同ランク更新や**クレジットキー**は交換可能な場合があります。

## 利用と請求

**利用と請求**でチャージ／付与と、チャット・Agent・画像の消費を確認できます。失敗して返還されない場合は時刻を控えてフィードバックしてください。

## カードキー交換

1. 交換画面でキー入力（多くは `XXXXX-XXXXX-XXXXX-XXXXX`）。
2. 主な種類：
   - **会員**：プラン有効化＋月次クレジット
   - **クレジット**：残高加算
3. 即時反映。法令または明示ポリシー以外、原則返金不可。

## Agent 設定（アカウント → Agent）

エディタの Auto ポップオーバーと同一のローカル設定です。

### Auto ルーティング

| 設定 | 効果 |
|------|------|
| Standard | プラットフォーム既定レーン表 |
| Pro / Max | より強いプリセットマップ |
| Custom lanes | fast / standard / reasoning / multimodal / image を個別指定 |

**チャットが Auto のときのみ。** 詳細は [Agent · Auto](/guide/agent#auto-ルーティング設定)。

### サードパーティ

名前、API Key、互換 Base URL、種別（対話 / マルチモーダル）を保存。Key はブラウザのみ。対象プランが必要です。

## プロフィール

- 表示名・自己紹介・アバター（オブジェクトストレージ）。
- ログイン：メールまたは Google。
- メールアカウントは設定で**パスワード変更**可。Google のみの場合は通常メールパスワードなし。

## お知らせ

**お知らせ / 通知**で製品告知とシステム通知。すべて既読にできます。
