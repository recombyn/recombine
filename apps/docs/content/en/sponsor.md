# Sponsor recombyn

Hi — I’m the solo developer behind recombyn.

I used to write code for a living. Nothing fancy on the degree side, years in outsourcing, work that never felt very stable. Then, sure enough, I got laid off. I looked for a long time and still couldn’t land anything that fit. For a while I didn’t know what else to do, so I started building something I actually wanted — and that’s how recombyn showed up.

No team, no fundraising story. Nights and weekends, patching holes as I learn. The product still has plenty of rough edges — stability, polish, docs, how to make it sustainable… I know. I thought about raising money, but it’s a slog; turning it into a “proper” SaaS means licenses and compliance that one person can barely carry.

There’s no forced plan here, and nothing like “sponsor or you can’t use it.”  
If it helped you — or you just want to back an indie developer who’s still hanging on — **voluntary support** is enough.

Thanks for reading this far.

## Community

Sponsorship isn’t buying a feature pack. It helps this small project last longer: fix bugs, ship capabilities, and respond to feedback. Using it, sharing it, or opening an issue helps too.
