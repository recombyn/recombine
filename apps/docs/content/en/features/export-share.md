# Export & share

## Export

Top bar **Export**:

- **Current artboard**, **selection**, or **all pages** (multi-frame)
- Formats: PNG / JPG / SVG (per product options)
- Scale ≈ 0.5x–4x
- Single nodes can export or fullscreen-preview from their toolbar

Confirm the export range on multi-artboard projects.

## Share links

**Share** creates a link:

| Type | Notes |
|------|-------|
| **View only** | Anyone with the link can view; **no sign-in** |
| **Can edit** | Sign-in required; only **owner and invited collaborators** can save edits |

With the public link off, usually only collaborators can open the file. Don’t put secrets in public view links.

If you open an edit link without access, you’ll get view-only (or a prompt to ask for an invite).

## Invite collaborators

In Share, invite by **username / email / user ID**:

1. Open **Share** → invite.
2. Search and add the person.
3. They sign in and edit within their access (edit links still require them on the collaborator list).

Manage members in the collaborator list. Profile “share” may say coming soon — follow in-product UI.
