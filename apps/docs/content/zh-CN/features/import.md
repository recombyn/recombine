# 导入文件

首页支持将本地文件导入为可编辑画布内容。

## 支持类型

| 类型 | 说明 |
|------|------|
| **图片** | 导入为图片节点，可继续用 [图片编辑工具](/guide/image-tools) 与 Agent |
| **PDF** | 尽量转为画布结构（文字 / 图形等），便于再排版 |
| **Word** | 转为可编辑内容后继续设计 |

具体扩展名与大小限制以产品上传提示为准。

## 建议流程

1. 在首页选择导入，或把文件拖入导入区（若界面支持）。
2. 等待解析完成并进入编辑器。
3. **检查画板尺寸**是否符合目标场景（海报 / 手机 / 网页等）。
4. 在 [图层面板](/guide/canvas#图层) 理清顺序，隐藏不需要的层。
5. 用 Agent 统一风格、改文案或替换配图；局部也可用手动工具精修。

## 注意

- 复杂 PDF / Word 的排版可能与原稿有差异，属转换近似，不是像素级还原。
- 扫描件或纯图片 PDF 可能更接近「整页图」，可再配合去背景、裁剪或 Agent「编辑文字」拆层。
- 导入后的项目同样会走云同步与导出 / 分享流程。
