# 导出与分享

## 导出

编辑器顶部 **Export**：

- 选择**当前画板**、**选中内容**或**导出全部页面**（多画板时）
- 格式：常见为 PNG / JPG / SVG（以产品内选项为准）
- 倍率：约 0.5x–4x，按用途选清晰度
- 单节点也可在选中后从工具条导出或全屏预览

下载到本地后即可用于投放、印刷或二次设计。多画板项目请确认导出范围是否包含全部需要的页面。

## 分享链接

**Share** 可生成链接（开启后可复制发给他人）：

| 类型 | 说明 |
|------|------|
| **仅预览** | 持有链接者可查看，**无需登录** |
| **可编辑** | 打开后需登录；仅**所有者与受邀协作者**可改稿并保存 |

未开启公开链接时，通常仅文件协作者可访问该文件（以界面开关文案为准）。请勿在公开预览链接中放置敏感信息。

若你打开别人的可编辑链接但没有权限，界面会提示仅可预览，或请所有者邀请你为协作者。

## 邀请协作者

在分享面板中可按**用户名 / 邮箱 / 用户 ID** 邀请协作：

1. 打开 **Share** → 邀请协作。
2. 搜索并添加对方。
3. 对方登录后即可在授权范围内打开并编辑（可编辑链接仍需其账号已在协作者列表中）。

可在协作者列表中管理已邀请成员。个人主页「分享」能力若显示即将开放，以产品内为准。

## 发布到广场

将作品 **发布到广场** 后需管理员审核通过才会公开展示。封面与画板要求见 [广场与灵感](/features/plaza)。
